## 🚀 Quick Start Guide

### Option 1: Web Interface (Recommended)

1. **Start the application:**
   ```bash
   cd /vercel/sandbox/beat-blood-neon-installer
   npm start
   ```

2. **Open your browser:**
   ```
   http://localhost:3000
   ```

3. **Follow the steps:**
   - Click "Start Installation" to download dependencies
   - Click "Build APK" to compile and generate APK
   - Copy the download link or scan the QR code

### Option 2: Command Line

1. **Run automated installation:**
   ```bash
   cd /vercel/sandbox/beat-blood-neon-installer
   ./install.sh
   ```

2. **Build APK:**
   ```bash
   ./build-apk.sh
   ```

3. **Find your APK:**
   ```bash
   ls -lh /vercel/sandbox/output/*.apk
   ```
