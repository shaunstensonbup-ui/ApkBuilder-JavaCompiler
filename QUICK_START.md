## ⚡ Instant Start (3 Steps)

### 1️⃣ Start the Web Interface
```bash
cd /vercel/sandbox/beat-blood-neon-installer
npm start
```

### 2️⃣ Open Browser
```
http://localhost:3000
```

### 3️⃣ Build Your APK
- Click **"Start Installation"** → Wait for completion
- Click **"Build APK"** → Get download link + QR code

## 🛠️ Alternative: Command Line

### Run Automated Installer
```bash

./install.sh
```

### Build APK Manually
```bash
./build-apk.sh
```

### Find Your APK
```bash
ls -lh /vercel/sandbox/output/*.apk
```
